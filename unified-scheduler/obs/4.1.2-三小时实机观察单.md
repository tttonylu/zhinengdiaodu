## 1. 本地口令（x.com 控制台，可复制）

### 1.1 开跑快照（只跑一次）

```javascript
(async () => {
  const ver = await __sgExtVer();
  const q = JSON.parse(sessionStorage.getItem('dan_ice_task_queue') || 'null');
  const seen = JSON.parse(sessionStorage.getItem('dan_session_scanned') || '[]');
  const ops = JSON.parse(sessionStorage.getItem('ops_target_rounds') || '{}');
  const done = JSON.parse(sessionStorage.getItem('dan_completed_targets') || '[]');
  const out = {
    at: new Date().toLocaleString('zh-CN', { hour12: false, timeZone: 'Asia/Shanghai' }),
    ver,
    phase: sessionStorage.getItem('dan_chat_phase'),
    auto: sessionStorage.getItem('dan_auto_run'),
    queue: q && {
      sealed: q.sealed, total: (q.items||[]).length,
      pending: (q.items||[]).filter(i=>i.status==='pending').length,
      skipped: (q.items||[]).filter(i=>i.status==='skipped').length,
      deferred: (q.items||[]).filter(i=>i.status==='deferred').length,
      doing: (q.items||[]).filter(i=>i.status==='doing').length
    },
    cellsSeen: seen.length,
    opsMapSize: Object.keys(ops).length,
    completedToday: done.length
  };
  console.log('[4.1.2 boot]', out);
  copy(JSON.stringify(out, null, 2));
  return out;
})();
```

### 1.2 每小时抽检（T+1h / T+2h / T+3h）

```javascript
(async () => {
  const ver = await __sgExtVer();
  const q = JSON.parse(sessionStorage.getItem('dan_ice_task_queue') || 'null');
  const seen = JSON.parse(sessionStorage.getItem('dan_session_scanned') || '[]');
  const items = (q && q.items) || [];
  const tally = items.reduce((a,i)=>{ a[i.status]=(a[i.status]|0)+1; return a; }, {});
  const pendingSample = items.filter(i=>i.status==='pending').slice(0,8).map(i=>({h:i.handle,k:i.kind}));
  const skippedSample = items.filter(i=>i.status==='skipped').slice(0,8).map(i=>({h:i.handle,r:i.reason}));
  const mismatch = items.length < seen.length;
  const out = {
    at: new Date().toLocaleString('zh-CN', { hour12: false, timeZone: 'Asia/Shanghai' }),
    version: ver && ver.version,
    url: location.pathname,
    phase: sessionStorage.getItem('dan_chat_phase'),
    step: sessionStorage.getItem('dan_auto_step'),
    target: sessionStorage.getItem('current_target'),
    sealed: !!(q && q.sealed),
    cellsSeen: seen.length,
    queueTotal: items.length,
    tally,
    mismatch,
    pendingSample,
    skippedSample
  };
  console.log('[4.1.2 hourly]', out);
  copy(JSON.stringify(out, null, 2));
  return out;
})();
```

**本地红灯（任一即记 FAIL/BLOCKED）：**

| 现象 | 含义 |
|------|------|
| `version !== 4.1.2` | 未重载 → **BLOCKED** |
| seal 后 `mismatch===true`（total &lt; seen） | 登记漏人 → **FAIL** |
| 完结号出现在 `pendingSample` 且被点进资料/会话 | 完结仍开人 → **FAIL** |
| 控制台对 skipped 仍有 `click` / `chatGo` | 同上 |
| 整趟 `queueTotal===0` 但粉丝列表有人（Force 后） | Force 清键回潮 → **FAIL** |

## 2. 后台口令（OPS，把 `@bot` 换成实机号）

在 OPS 所在机或已代理的浏览器打开（路径按你现网）：

```text
GET /api/monitor/logs?account=@bot&event_id=chat.fan_roster_seal&limit=20
GET /api/monitor/logs?account=@bot&event_id=chat.fan_roster_gap&limit=20
GET /api/monitor/logs?account=@bot&event_id=chat.fan_roster_reclassify&limit=20
GET /api/monitor/logs?account=@bot&event_id=chat.session_verdict&limit=40
GET /api/monitor/logs?account=@bot&event_ids=chat.task_queue_built,chat.task_item_done&limit=40
GET /api/plugin/dm/rounds/@bot
```

**后台判读：**

| 信号 | 期望 |
|------|------|
| `fan_roster_seal` | 每趟触底 seal 至少 1 条；`mismatch:false`；`queueTotal≈cellsSeen` |
| `fan_roster_gap` | **应为 0 条**；有则 FAIL |
| `fan_roster_reclassify` | 可有；说明 seal 前纠过分 |
| `session_verdict` | 有发送才应抬轮；OPS 拒发不应抬本地轮次 |
| `dm/rounds` | `completed_targets` / `target_rounds` 与本地 skipped/pending 方向一致 |
