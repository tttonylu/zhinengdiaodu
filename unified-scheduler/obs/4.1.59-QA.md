# 4.1.59 QA：可发正向三态检测

## 方法（固定正向标记，只扫会话面板）

| verdict | 标记 | 动作 |
|---------|------|------|
| `can_send` | `dmComposerTextInput` / `Unencrypted message` | 破冰/跟进 |
| `hard_closed` | `has a closed inbox` 或按钮 `Use X Number` | 永久 skipped |
| `pending` | 都未命中 | 等框 / deferred，不永久杀 |

控制台：`await __sgDmSendability()`

## 验收
1. closed inbox + Use X Number 页 → `verdict=hard_closed`，toast 无法私信已拉黑
2. Unencrypted 空会话 → `verdict=can_send`，破冰一次
3. 进页后框晚出 → 先 pending/等，后 can_send，不进 skipped
4. 面板版本 **4.1.59**
