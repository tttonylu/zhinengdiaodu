## 二、P0 问题表（静态审查）

### P0-1 幽灵 `matrix_follow_running` 可永久阻塞私信

| 项 | 内容 |
|----|------|
| **结论** | **确认 · 需修复** |
| **位置** | `scheduler-core.js` `isFollowRoundActiveCo` L1129–1131；`content_chat.js` `isFollowRoundActive` L728–730 |
| **机制** | `localStorage.matrix_follow_running === 'true'` 时**直接 return true**，不检查 `sg_module_follow.phase` |
| **对比** | `enterSoftRiskDiversion` 会清除该标志（L3170）；正常填窗路径安全 |
| **风险路径** | `coGentleStopFollow` 设 `phase=soft_cooldown` 但未清 LS 标志；若 `enterSoftRiskDiversion` 因 idempotency guard 提前 return（已在软风控窗），关注引擎可能仍跑且 LS 标志残留 |
| **reconcileGhostFollowFlags** | 仅处理 `mfOn && !ms.running`（L1151–1161），不处理 `mfOn && phase===soft_cooldown` |
| **修复建议** | `isFollowRoundActive*` 先读 `sg_module_follow`：若 `phase` 为 `soft_cooldown`/`quota_exhausted`/`completed`/`done` 则返回 false，再检查 LS 标志；`reconcileGhostFollowFlags` 同步清除「phase 已结束但 LS 仍在」 |

### P0-2 `co_timeout` 依赖事件链停止关注引擎

| 项 | 内容 |
|----|------|
| **结论** | **确认 · 边缘路径需加固** |
| **位置** | `scheduler-core.js` L1977–1983 `coGentleStopFollow`；`content_follow_v1522.js` L3889–3896 监听器 |
| **机制** | 超时顺序：dispatch `sg-follow-round-end` → listener 调 `enterSoftRiskDiversion`（清标志+stopBot）→ `coGentleStopFollow` |
| **正常路径** | 同步事件链，listener 先执行，应能停止 |
| **风险路径** | idempotency guard（L3142–3144）导致 listener 无操作；协调器认为 follow 已停，引擎循环可能继续至 90s 心跳超时 |
| **修复建议** | `co_timeout` 分支补充 `coStop('follow')` 或 `sg-follow-command stop`；或 `coGentleStopFollow` 内主动清 `matrix_follow_running` |

### P0-3 SOFT 风控入口不一致（自动模式）

| 项 | 内容 |
|----|------|
| **结论** | **确认 · 需修复** |
| **位置** | `runEngine` L3423–3426 vs `handleFollowButton` L2458–2460 |
| **行为差异** | 循环开头 `startLimit==='SOFT'` → `navigateToHomeForWarmup`（仅 `followNextDelayUntil`，**无** `softRiskUntil`） |
| | 点击路径 `preLimit==='SOFT'` → `enterSoftRiskDiversion`（15–18min 填窗 + 协调器 `applySoftRiskPriority`） |
| **影响** | 自动模式若 SOFT 在循环入口触发，协调器**不会**进入软风控填窗，关注冷却后直接恢复，与设计文档不符 |
| **修复建议** | 自动模式下 L3423 改为 `enterSoftRiskDiversion()`（与点击路径一致） |

### P0-4 填窗 idempotency 静默丢弃二次触发

| 项 | 内容 |
|----|------|
| **结论** | **确认 · 低频发但需知** |
| **位置** | `enterSoftRiskDiversion` L3141–3144 |
| **机制** | 已在 `softRiskUntil` 窗内时直接 return，不 stopBot、不清标志 |
| **叠加 P0-2** | 超时 + 已在填窗 → 关注引擎可能不被二次停止 |
| **修复建议** | guard 内至少执行 `stopBot()` + 清 `matrix_follow_running`；或记录 telemetry 便于排障 |
