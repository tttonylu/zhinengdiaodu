# 4.1.53 QA 验收单

> 基线扩展 **4.1.53** · 私信逻辑补全

## 每机

1. 重载扩展，标题含 **4.1.53**
2. PIN 默认 2546（或 OPS `chat_dm_pin`）

## 阻断项

| ID | 步骤 | 期望 | ☐ |
|----|------|------|---|
| Q1 | 空白 + Unencrypted + 无 iceSentAt | 强制破冰，`round→1`；verdict 可有 `blank_force_ice` | ☐ |
| Q2 | 空会话资料壳（Joined/Followers/显示名） | 不 peer_first、不跳破冰 | ☐ |
| Q3 | round1 有真灰泡 | 发 AD（或&lt;25 婉拒） | ☐ |
| Q4 | AD 后 kickCount0 | toast **盾牌**，发 `kick_message` | ☐ |
| Q5 | 间隔后再开 kickCount1 | toast **催加**，发 `final_kick_message`；再开完结 | ☐ |
| Q6 | Passcode 门 | 自动填 **2546**，toast「已填 PIN…」；解锁后继续发 | ☐ |
| Q7 | 无框 + Use X Number | 拉黑 skipped，不再开 | ☐ |
| Q8 | URL | 不进 `/i/chat` 列表根 | ☐ |

## 口述检查

- round0/1/2/3 ≠ chat1/chat2 时间片
- AD 后只有 **盾牌一次 + 催加一次**（不是催 4 次）
