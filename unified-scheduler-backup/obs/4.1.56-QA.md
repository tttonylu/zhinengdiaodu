# 4.1.56 QA：发出即本地计数

## 现象
同人连续多条破冰（例 3:25×2 + 3:26）；黄条「已发出但后台记账失败，本轮未计数」。

## 根因
`recordDmAndAdvance`：气泡已确认，但 `opsDmRecord` 失败 → **不** `advanceRound` / 不标队列 done → 下一拍仍当未破冰再发。

## 修复
UI `confirm.ok` 后一律本地推进；OPS 失败 toast 改为「已按本地计数」，verdict `ops_report_failed_local_ok`。

## 验收
1. 故意断 OPS / 超时：破冰仍只发一条，本地 round≥1、有 iceSentAt
2. 同人不应在 1 分钟内出现第 2/3 条破冰
3. 版本 **4.1.56**
