# 4.1.57 QA：无框即无法私信

## 现象
会话底部无输入框，却黄条「破冰气泡未确认，本趟跳过（下窗再试）」——未拉黑，下窗再点进。

## 根因
1. `detectDmSendUnavailable` 要求无框 **且** Use X Number/硬文案；纯无框返回 false  
2. `no_bubble` 首次走 deferred  
3. 寻框曾回退到页内其它 textbox → 假「可发」

## 修复
- 私信 UI 内只认面板 composer  
- 会话页无框 → `detectDmSendUnavailable=true`  
- 发送失败 + 无框 → 立即 `finalizeUnsendablePeer`

## 验收
1. 无输入框会话 → toast「无法私信已拉黑」类，队列 skipped，不再点进  
2. 有 Unencrypted 框空会话 → 仍可破冰  
3. 版本 **4.1.57**
