# 4.1.55 QA：禁二次破冰

## 现象（回归）
同人两次破冰问年龄（例：今日 0:06 + 3:25），对方无回复、仅我方蓝泡。

## 根因
4.1.54 `isBlankDmThread` 只认「无对方灰泡」→ 已破冰未回也当真空；`blank_force_ice` 还 `delete iceSentAt` 再发。

## 修复
- 真空 = 无可发框内真气泡（**我方或对方**都没有）
- 仅 `!iceSentAt && 真真空` 才 `blank_force_ice`
- 有 `iceSentAt` 即使 DOM 像空 → `blank_skip_reice`，不重发

## 验收
1. 空会话（Unencrypted、无蓝泡）→ 仍破冰一次，`blank_force_ice` 可有
2. 已有一条破冰蓝泡、无灰泡 → **不再**发第二条破冰；toast 可为「跟进」后 `no_reply` deferred
3. 有灰泡 → 仍走年龄/AD
4. 面板版本 **4.1.55**；OPS 不应再对同人连出两次 `ice_sent` 且间隔仅数小时、中间无 reply
