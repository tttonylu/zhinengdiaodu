## 3. 4.1.15 改了什么（针对截图那条 toast）

现象：已在真会话发出破冰，却弹「会话与目标不一致，跳过」。

根因（守箱关仍生效的残留）：

1. `getChatPhase()` 在 `/i/chat` 上默认成 `inbox`
2. 无 step 时在 Messages 页武装 step2，人钉在收件箱 UI
3. step2 身份硬门按守箱规则 `inboxQueueMark` + toast

已改：

- 守箱关 → 相位默认 **outbound**（禁止 URL→inbox）
- 守箱关主循环 → **禁止** Messages 武装 step2；一律回 `/followers` 再 drain
- 粉丝队列错会话 → `deferred` + 回粉丝页，**不再**弹「不一致」、不写 inbox skipped
- 开人前若仍在旧 DM → 先回 `/followers`
- step4 守箱关/outbound → 强制回粉丝页
