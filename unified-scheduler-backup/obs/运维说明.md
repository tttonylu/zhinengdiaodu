# 运行观测与排障说明（非技术版）

> 开发改功能前请先读仓库根文档：**[`docs/工作指导.md`](../../docs/工作指导.md)**（按板块改，避免一处改崩多处）。

## 你能看到什么

插件会把关键运行事件自动记到本地，并定期上报到 **OPS 后台 → 运行日志**。

常见事件（中文）：

| 现象 | 日志里可能显示 |
|------|----------------|
| 私信一直没启动 | **私信被挡**（冷却中 / 日帽已满 / 策略禁止） |
| SCRM 不让发私信 | **SCRM挡私信** |
| 守箱找不到消息 | **守箱 DOM 未命中** |
| 发送失败 | **发送失败** |
| 系统异常 | **系统错误** / **系统警告** |

## 面板一键操作

在 X 页面右下角 **调度面板**：

1. **上报诊断** — 把最近 200 条事件 + 当前页面状态打包发到 OPS，适合「帮我看看这个号怎么了」。
2. **复制诊断** — 同上，但复制到剪贴板，可粘贴到微信/邮件发给技术支持。
3. **最近日志** — 面板底部显示最近 5 条中文摘要，不用开后台也能瞄一眼。

> 上报后约 1 分钟内，在 OPS **账号详情 → 运行日志** 或 **运行日志** 页可看到。

## OPS 后台怎么看

1. 打开 **运行日志**（左侧导航）。
2. 可按 **账号 / 分类 / 级别 / 事件 ID** 筛选。
3. 点 **导出 JSON** 可下载存档。
4. 进入 **账号中心 → 某账号详情**：
   - **运行日志** 区块：该号最近 30 条。
   - **最新诊断包**：插件点「上报诊断」后的完整快照，可下载 JSON。

## 告警（PushPlus）

在 **系统配置 → 调度设置 → 运行观测** 可开关：

- **PushPlus 告警**：SCRM 挡私信、连续发送失败、守箱 DOM miss 等会自动推送到已配置的 PushPlus。
- **告警去重**：同一账号同一类问题 N 小时内不重复推送（默认 2 小时）。
- **上传最低级别**：调为 `warn` 可减少上报量；排障时可临时改为 `info` 或 `debug`。

## 反馈问题时请提供

1. 账号 handle（如 `@xxx`）
2. 大概发生时间（上海时区）
3. 面板点一次 **上报诊断**，或 **复制诊断** 发全文
4. 简述现象：例如「守箱 20 分钟没清债」「私信一直显示冷却」

## 常见问题

**Q：运行日志是空的？**  
A：确认插件在线、OPS 地址配置正确；面板是否有「最近日志」；可把上传级别调到 `info` 后重试。

**Q：事件太多怎么办？**  
A：在配置里把「上传最低级别」改为 `warn`，或在「禁用事件」里填不需要的 `event_id`（逗号分隔）。

**Q：和「最近操作」有什么区别？**  
A：**最近操作**是业务动作（关注、破冰、广告等）；**运行日志**是调度/守箱/挡板/异常等排障信息。

## 测试聊天话术（干跑 + 真发）

### 干跑预览（不发信）

1. OPS → **系统配置 → 私信设置** → 勾选 **干跑预览** 并保存；或插件面板点 **干跑预览**（仅当前标签页）。
2. 面板点 **只私信**，让引擎跑到待发步骤。
3. 页面底部圆钮打开 **中控台**，或 OPS **运行日志** 搜 `干跑预览` / `Console日志`。
4. 点 **上报诊断** → 账号详情 **查看详情** 可看完整待发话术。

### 真发测试（小号）

1. OPS 仪表盘 → SCRM **紧急强制 +6h** 或 **关闭闸门**。
2. 确认话术池与推广链接已保存；测试号在 OPS 已注册（日私信条数上限已废除，勿再依赖 `daily_dm_limit`）。
3. 面板 **干跑 OFF**，点 **只私信**。
4. 工作时段内（默认 08:30–18:00）观察 OPS **最近操作** 与 **运行日志**。

### 放行检查

在 x.com 控制台执行 `await __sgDiag()`，看 `chatDiag.opsGateReason` 应为空或 `force:...`；`actionableAdDebt` / `actionableKickDebt` 为当前可处理的债（有未读回复 / 催加 SLA 到期）。

## 关注轮次与软风控填窗（自动模式 v3.4.9）

> **必读 · 关键业务规则**：一次领号 = 一个博主，**必须把当前博主的粉丝列表点完**（约 50 个，滚到底为准）才切换下一个博主。连续点约 **15 个**后 X 触发软风控 → 休息 **15–18 分钟**（期间自动做私信或养号）→ **休息后跳回当前博主**继续点（不换号，已点过的不重复）→ 当前博主点完才领下一个。

调度按时间片轮转，**关注进行中不做私信拓客/OPS 拉取**（手动「只私信」除外）。

| 阶段 | 大约时长 | 做什么 |
|------|----------|--------|
| **关注轮次** | 单次最长 **20 分钟**；点击间隔 **5–8 秒** | 只跑关注，私信让路 |
| **轮次结束填窗** | 20min 超时 / pool 扫完 / 日配额满 / SOFT → **15–18 分钟** | **约 85% 私信** / 其余养号（冷却中则只能养号） |
| **死号快速跳过** | 连续跳过 **3** 个死号/封禁 | 强制填窗（正常扫完仍立即填窗） |
| **S3 优先级** | 私信时段且关注配额未满 | **关注优先于私信**（软风控/赶工窗除外） |
| **赶工 vs 填窗** | 17 点赶工 | 不覆盖软风控**养号**填窗 |
| **软风控 → chat** | 窗内 | `sg-soft-risk-chat-start` → 立即刷新 OPS |
| **软风控结束** | — | `followNextDelayUntil` 到期后恢复关注，**回到当前博主粉丝列表续点** |

自动模式：**关注循环内定时养号已禁用**，养号由填窗分流或协调器启动。

面板 `软风控` 行可看剩余秒数；`await __sgDiag()` 可看 `softRisk` / `followRoundStartedAt`。

## 私信双战场（v3.4.5+）

| 战场 | 页面 | 做什么 |
|------|------|--------|
| **拓客** | 自己的 `/followers` | 只对新回关发破冰（OPS round=0）；已破冰的扫到即跳过，**不再点进主页** |
| **跟单** | `/messages` | 广告债：必须有**未读/回复**才处理；催加债：按 SLA 到期处理；无可处理目标则**立即结束**（不再空等 8 分钟） |

- **DM PIN**：进入加密私信时自动填入 PIN（默认 `2546`，可在 OPS `sg_config_thresholds.chat_dm_pin` 覆盖）。
- **粉丝扫描**：本地 DOM 每 30s（仅软风控 chat 窗或关注已让路时）。
- **OPS 轮次**：关注轮次结束进入软风控 chat 窗时立即拉；outbound 开始 / 发信成功后拉；其余约 90s 错峰。

## 测试监控（v3.6.3+，3.7.18 仍适用）

用于验收调度逻辑（填窗、让路、死号计数等），**不影响正常运行**，仅记录状态与事件。

> **24 小时 Soak**：见 [`24h-soak-准备清单.md`](24h-soak-准备清单.md)。面板开 **24h测试ON**（全天放开时间窗）+ **日志常态ON** + SCRM 放行后点 **自动**。

### 如何开启

1. 在 X 页面打开 **调度面板** → 确认 **日志常态ON**（加载即采；未开则点一次恢复）。
2. 或在控制台执行：
   - `await __sgTestMonitor.start('24h-soak')` — 开始/打标签
   - `await __sgTestMonitor.stop()` — 停止

### 面板操作

| 按钮 | 作用 |
|------|------|
| **测试监控** | 开关监控（ON 时显示统计 + 最近 3 条） |
| **导出测试** | 下载 JSON 文件到本地 |
| **上报测试** | 打包发到 OPS（含 `test_monitor` + 当前诊断） |
| **清空** | 清空当前会话记录（不关监控） |

### 控制台命令

```javascript
await __sgTestMonitor.isActive()   // 是否在监控
await __sgTestMonitor.export()     // 查看完整导出包
await __sgTestMonitor.download()   // 触发下载
await __sgTestMonitor.upload()     // 上报 OPS
await __sgTestMonitor.getRecent(5) // 最近 5 条记录
```

### 导出 JSON 主要字段

| 字段 | 含义 |
|------|------|
| `session.records` | 事件流：`state_change` / `lifecycle` / `telemetry` / `diagnostic` / `error` |
| `session.summary` | 计数：协调 tick、填窗次数、轮次结束、私信被挡、错误 |
| `session.checkpoints` | 每 30 秒精简诊断快照 |
| `current_diag` | 导出时刻完整 `__sgDiag()` |

### 验收场景对照

| 想验证的现象 | 在 records 里找 |
|--------------|----------------|
| 关注轮让路私信 | `state_change` 中 `followRoundActive: true→false` |
| 进入软风控填窗 | `lifecycle` 含 `sg-soft-risk-entered` |
| 关注轮结束（任意原因） | `lifecycle` 含 `sg-follow-round-end`（`quota_full`/`dead_skip_threshold`/`co_timeout` 等） |
| 死号 3 次触发填窗 | `lifecycle` 含 `sg-follow-round-end` reason `dead_skip_threshold`；`diagnostic` 含「💀 死号跳过 3 次」 |
| 私信被调度挡住 | `telemetry` 含 `scheduler.chat_blocked` |
| 幽灵关注旗标清除 | `telemetry` 含 `scheduler.ghost_follow_flag` |

## DM 收件箱回复识别与链路诊断（v3.7.29）

| 能力 | 说明 |
|------|------|
| **仅年龄分流** | 只认年龄数据：`&lt;25` 婉拒；`≥25` 或解析失败 → 广告；支持长句单位年龄与多句/多气泡；关键词婉拒已废除 |
| **inbox_done 可覆盖** | 探空仍防空转；同行出现 replied/unread 时可重开；等待期亦不写入 done |
| **轮次只升不降** | OPS `current_round` 滞后时不再把本地婉拒/已发广告压回低轮次 |
| **预览年龄路由** | `await __sgPredictAgeRoute(['20'])` / `(['こんにちは','20歳です'])` |
| **路线 A 验收** | `await __sgAcceptRouteA('handle')` 分层检查 A1/A2/A3 |
| **收件箱** | aria 去时间/Unread；`You:`/话术判本方；对方文案 → replied |
| **iceSentAt 回填** | OPS 抬 round 或缺证据时自动补；启动扫全 bot 桶 |
