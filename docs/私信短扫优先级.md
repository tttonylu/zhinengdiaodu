# 私信短扫优先级（软风控脉冲）

> 基线：扩展 **≥ 3.7.56**  
> 相关：[`工作指导.md`](工作指导.md) · [`私信回扫读错SOP.md`](私信回扫读错SOP.md) · [`私信模块逻辑审查.md`](私信模块逻辑审查.md)

## 脉冲内强制顺序

```text
1. 可视未读（list urgent / unread_adopt）
2. 强回复预览（replied）
3. 仅当本脉冲已扫完可视区且无 1/2：才 probe_queue
4. 同一目标：对方文本相对上次处理无变化 → 不再打开/不再发
```

## 禁止项

- **禁止**在可视区仍有未读（`unread_dom|unread_visual > 0`）时用 `probe_queue` / `bottom_probe` 直接开聊  
- **禁止**可视区已有 `unread|replied` 时再 `enqueueInboxProbe`  
- **禁止**无新对方气泡时重复发送（含已废除的年龄追问）
- **禁止** round2 催加未就绪（`!kickReady`）因蓝点/旧回复反复打开（4.1.61 起按轮次就绪，不再等 `chat_kick_min_hours`）

## 发送分流（会话内）

- 无对方文本 → 结束并 `inbox_done`  
- 年龄明确 **&lt;25** → 婉拒  
- 年龄 **≥25** 或 **解析不出年龄**（寒暄）→ 发 AD  
- **不再** `need_age` 追问「年齢教えて」

## OPS 验收

- 有蓝点脉冲：`inbox_open via` ∈ `list` / `yield_over_probe` / `unread_adopt`（不应为 `probe_queue`）  
- 寒暄后：`chat.session_verdict` = `greeting_ad` 或 `ad_sent`  
- 对方先开口：先有 OPS round1 占位（或已有破冰），再 `greeting_ad`/`ad_sent`；不应持续 `round_gap`  
- 错会话：`gate_reason=target_mismatch`，无 `ad_sent`  
- 不应再出现 `need_age_reask`
